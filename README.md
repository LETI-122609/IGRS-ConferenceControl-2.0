# IGRS-ConferenceControl-2.0

## 1. Descrição do Projeto

O ConferenceControl 2.0 é um projeto desenvolvido no âmbito da unidade curricular de IGRS, que tem como objetivo desenvolver um sistema de gestão e controlo de conferências através de tecnologias e serviços de comunicação SIP.

O sistema pretende permitir a gestão de conferências, participantes e salas, bem como a comunicação entre os diferentes utilizadores.

## 2. Objetivos

Os principais objetivos do projeto são:

Desenvolver uma infraestrutura de comunicação baseada em SIP.

Implementar mecanismos de gestão e controlo de conferências.

Permitir a criação e gestão de salas de conferência.

Permitir a entrada e saída de participantes.

Implementar mecanismos de monitorização e gestão dos serviços.

Garantir a comunicação entre os diferentes componentes do sistema.

## 3. Tecnologias e Ferramentas

As tecnologias e ferramentas utilizadas no desenvolvimento do projeto incluem:

Kamailio – Servidor SIP.

Python – Desenvolvimento e implementação de funcionalidades.

Docker – Criação e gestão dos ambientes de execução.

Docker Compose – Orquestração dos contentores.

Git e GitHub – Controlo de versões e colaboração.

SIP – Protocolo de comunicação.
